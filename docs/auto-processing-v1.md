# 柜台烟盒图片自动处理方案 cabinet-v1

## 依据与目标

13张原图共439个模型识别项，A/B/C分别保留402项，D中性转换保留437项。以上是与原图模型输出的一致性，不能当成准确率；尚无人工标准答案，也未测量模型重复调用波动。第一版以D为回退，仅在亮度特征同时满足条件时轻微处理。目标是减少不必要干预，并为下一轮第三方验证生成可追溯输入；不是已经证实提高识别率的最优参数。

原始素材现位于用户数据目录的 input，文件1–8对应第一批，11–15对应第二批；统一编号9对应11.jpg。现有C参数文件为gamma=1.15且关闭CLAHE，不能把该轮结果单独归因于CLAHE。

## 特征分析

最长边缩至800像素；取中央 x=5%–95%、y=15%–90% 为参考区域，转LAB提取8位L通道，划分4×4块。记录中位亮度、P10/P90、L<50的暗部比例、L>245的高亮比例、块中位数低于125的占比、块中位数P90−P10跨度、各块P90−P10的中位数（局部对比指标）。

参考区域只是减少边缘背景干扰的固定裁剪，并非柜台/烟盒检测。黑色包装、白色包装、价签、反射均可能影响指标，分块亮度不同也可能来自不同包装，分类结果只代表候选处理条件。低对比和高亮只给提示，不直接触发强增强。当前不自动做反光修复、锐化、去模糊或目标检测。

## 决策和处理顺序

1. 偏暗：参考区域中位L<125，P90<200，至少25%分块中位L<125；使用gamma=1.08（公式L′=255×(L/255)^(1/gamma)）。
2. 否则，明暗不均：块中位数跨度≥65且至少12.5%块中位L<125；gamma=1.06，并用低分辨率高斯平滑的照明图生成连续权重，仅轻微抬升暗区。不是每块独立增强，不产生硬分块边界。
3. 其余正常或不确定：D式LAB往返转换及JPG保存，不作实质增强。

所有分支：brightness=0、contrast=1、denoise=0、CLAHE关闭、过曝压缩关闭。提亮增量限制在L通道8级内；L=180起渐弱，L≥240不提亮。原图分辨率不变，输出沿用现有OpenCV JPG编码方式。局部处理的Gamma是上限参数，不能只复制gamma字段重现结果，必须使用对应规则版本的auto模式。

阈值是由这批素材亮度分布得到的初始工程规则，不是统计训练或识别准确率校准结果。对单张图片颜色内容可能误判，下一批独立素材必须继续验证。

## 接入与复现

页面“自动分析”逐图处理，手动设置在该模式不参与选择。接口传mode=auto；未传mode仍为manual，兼容既有调用。所有接口返回processing；网页批量下载附处理记录。命令行 scripts/export_auto.py 可离线导出，清单包含SHA256，避免日后参数文件变动造成版本混淆；不覆盖已有输出。

验证执行：`.venv/bin/python -m unittest discover -s tests -v`、`npm test`、`npm run build`。测试覆盖中性分支与原流程一致、偏暗提亮、高亮保护、局部提亮、极端小图、上传API和参数模式、ZIP记录。

下一轮应将原图、D和自动结果按相同文件对应关系送测；记录完整品种列表，人工核对差异项，并对同一输入重复调用估计模型波动。中性分支用于稳定回退；如果提亮图片仍退化，应收紧规则或关闭对应分支。不要仅以总count最多选择方案，也不要用13张素材拟合复杂分类器。
