# 自动处理 cabinet-v3：曝光证据门控与原图直通

## 本次调整依据

Y/D/E的all_result.json去重品种数为149/149/148。E相对Y丢失七匹狼（观海中支）、黄山（黑马细支），新增娇子（宽窄醇香中支）。前两个品种在D中也不存在，不能认定为v2造成的损失；新增品种也尚未人工确认。逐图E相对D新增2项、丢失3项，未证明v2提亮或局部对比拉伸的识别收益。

因此本次调整是降低无依据干预，不是依据count拟合“最优增强”，更不承诺恢复某个品种。保留历史v1/v2输出、记录及ZIP；历史方案分别见auto-processing-v1.md、auto-processing-v2.md。

## 新规则

仍在最长边800像素的缩略图上统计中央参考窗口（x5%–95%、y15%–90%）的整体指标；在最长边1200像素的分析图上统计6×8区域。分析窗口不是柜台/烟盒检测，边缘密度不是OCR，噪声是代理指标。

默认不处理：只有整体曝光门控通过，才允许分区提亮。没有确认收益的自动局部对比拉伸关闭；CLAHE、降噪、锐化和过曝压缩继续关闭。

曝光门控先要求：分区噪声代理中位数≤6，且参考窗口L>245比例≤2%。在此基础上满足以下任一组联合条件：

1. 明显整体偏暗：中位L<105、P90在25（含）至185（不含）之间、P10<80，且4×4块中位L<125的比例≥50%。P90过低接近全黑时不强行提亮。
2. 明显暗区与亮区并存：中位L<140、P10<45、L<50比例≥15%、4×4块中位L的P90−P10跨度≥70，且暗块比例≥37.5%。局部提亮还须有至少8个受支持分区。

局部支持条件：边缘密度.04–.65、噪声代理≤6、中位L<110、P90<185、P90−P10跨度≥35。Gamma=1+clip((110−中位L)/400,.03,.12)。整体明显偏暗时，对中位L<140、噪声代理≤6的区设置gamma下限1.10。其他区gamma=1，不作对比拉伸。

这些阈值是本次保守收紧的工程假设，不是经第三方识别率验证的分类标准。未按文件名、品种名或图片编号配置例外。

## 像素与文件保护

增强分支仍使用平滑参数场、保持原分辨率；LAB L提亮上限从18收紧为10，不主动压暗。高亮保护维持L>200渐弱、L≥235不修改；近黑像素减弱提亮。色域裁剪、颜色转换和编码可能造成额外数值差异。

中性分支不再作LAB往返转换，直接使用原始解码像素。输入是真实JPEG、输出扩展名为jpg/jpeg时，原文件字节直接复制，不重复编码，同时保留原EXIF等元数据。PNG等输入转JPG时仍需编码，记录strategy=reencoded，不会把PNG原字节冒充JPG。

响应processing增加decision_gates解释曝光门控、baseline=original_pixels、output_encoding.strategy说明原图直通或重新编码。页面会显示“原图直通：未做增强，也未重新编码”，旧手动参数与接口默认manual保持兼容。

## 本批13张结果

**13张全部未通过新的曝光门控，输出JPEG与各自原图逐字节一致。** 这不是“新增强改善了识别”，而是明确回退原图，避免现阶段无依据的图像变化。

文件位于temp/auto_1022_v3，处理记录包含输入/输出SHA256；质量检查逐图验证字节一致。既然本批输入与原图相同，不建议将它作为新的增强方案再占一次送测。相同图片在第三方再次调用仍可能有模型波动，本地不能预测结果。

后续更明显的偏暗图片仍能触发有限提亮分支，需用独立素材验证。若要继续争取识别增益，必须先确认差异项是否真实存在，或在第三方允许时独立验证分区输入，不能继续凭已有模型结果数量调强增强。
