# 柜台烟盒分区自适应处理 cabinet-v2

## 目标与依据

v1以D为基线，仅4张轻微提亮。v2根据每张图片不同区域的特征选择参数，保持一张输入、一张输出和原始分辨率，不引入新模型或在线调用。已有Y/A/B/C/D结果没有人工标注，D更接近原图输出不等于准确率最高。本版是候选方案，尚未证明提高识别率，也没有恢复反光遮挡、失焦或原图缺失的细节。

## 分区判断

整体分析仍取最长边800像素、中央x=5%–95%、y=15%–90%的参考窗口。局部分析在最长边1200像素缩略图上划分6×8区。缩略图只用于分析，输出使用原始尺寸。

每区计算中位L、P10/P90跨度、Sobel梯度幅值>40的比例、相对于3×3中值滤波的残差中位数/.6745（噪声代理）、L≥235占比。参考窗口不代表已经检测到柜台，包装配色、地板和玻璃纹理都可能影响指标。这些指标也不代表检测到文字或已经评估可读性。

- 有边缘线索：梯度比例在.04–.65之间，且噪声代理≤6。
- 局部偏暗：有上述线索，中位L<140、P90<215、动态范围≥35；gamma=1+clip((145−中位L)/300,.04,.20)。至少3区满足才启用。
- 整体偏暗：参考窗口中位L<125、P90<200且4×4暗块比例≥25%；参考窗口gamma下限1.18。gamma实际公式为L′=255×(L/255)^(1/gamma)。
- 局部低对比：有上述线索，动态范围35–95，中位L80–205，高亮比例<2%；增益为1+clip((100−动态范围)/350,.02,.14)，至少3区满足才启用。
- 正常或不确定：无条件命中时回退D式中性转换。不因均匀灰区或纯噪声就开启局部对比增强。

以上是初始工程阈值，不能保证区分所有噪声和纹理，也没有识别率标注校准。

## 实际处理与保护

每区生成gamma、对比增益和亮度中心；插值并平滑的是参数图，不是原图。参数在区域之间和参考窗口边界连续过渡，避免硬拼接接缝，不锐化或模糊文字。局部对比围绕分区中位L作线性拉伸，单项幅度限制±6，不使用CLAHE。

仅改LAB L通道，总增量限制为−6至+18；L>200渐弱，L≥235不修改；近黑像素渐弱。关闭降噪、CLAHE、过曝压缩与锐化。先在低分辨率生成参数场，再逐条带处理原图以控制内存。a/b通道不主动修改，LAB/BGR色域裁剪及JPG编码仍可能造成额外数值变化，因此“高亮不变”指编码前相对于D中性转换的像素值。

## 接口与复现

页面自动模式走v2，保留手动模式和旧参数JSON导入。接口mode=auto，processing含rule_version、分区统计与参数、各类命中数量，以及实际LAB L增量和变化像素占比。Gamma和对比增益是上限，不能复制单个值当成全图配置重现；须使用相同版本代码和auto模式。

```bash
.venv/bin/python scripts/export_auto.py --input /absolute/path/input --output /absolute/path/new-output
```

本批输出位于temp/auto_1022_v2，包含13张JPG、输入/输出SHA256、逐图分区处理记录、质量检查和说明；打包temp/auto_1022_v2.zip。v1的temp/auto_1021及旧ZIP保留。temp为Git忽略的本地产物，不随源码分发。请不要混用送测版本。

## 验证与限制
